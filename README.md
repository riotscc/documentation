# Riots.cc Documentation

The official documentation repository for [Riots.cc](https://riots.cc).

Riots.cc is a platform that brings your identity, social accounts, projects, and everything else together in one place. Create a personalized profile, customize your online presence, and share everything through a single link.

This repository contains the source files for the official Riots.cc documentation, helping users understand the platform, discover features, and troubleshoot issues.

## About the Documentation

Our documentation provides information about:

- **Getting Started** — Creating an account, setting up your profile, and getting started with Riots.cc.
- **Dashboard** — Managing your account, profile settings, appearance, and links.
- **Customization** — Personalizing your profile to match your identity.
- **Public Profiles** — Understanding how your profile appears to visitors.
- **Account & Security** — Managing account settings, privacy, and security.
- **Help & Support** — Troubleshooting problems and finding answers to common questions.

The documentation is built using [Mintlify](https://mintlify.com), allowing us to provide an organized, accessible, and easy-to-navigate experience.

## Contributing

We welcome contributions from the community!

Whether you're fixing a typo, improving an explanation, updating outdated information, or suggesting an entirely new documentation page, your contributions help make Riots.cc better for everyone.

### How to Contribute

1. **Fork the repository** — Create your own copy of this repository using GitHub's Fork button.
2. **Create a branch** — Make a new branch for your proposed changes.
3. **Make your changes** — Edit or add documentation files as necessary.
4. **Commit your changes** — Write a clear commit message describing what you changed.
5. **Open a Pull Request** — Submit your changes to the original repository for review.

Our maintainers will review your pull request and may request additional changes before merging it.

### Contribution Guidelines

To maintain consistent and helpful documentation, please follow these guidelines:

- Write documentation in clear, professional English.
- Keep explanations concise, accurate, and easy to understand.
- Follow the existing structure and formatting of documentation pages.
- Use Markdown or MDX formatting where appropriate.
- Ensure that links, examples, and instructions work correctly.
- Avoid making unrelated changes in the same pull request.
- Do not include personal information, credentials, or sensitive data.
- Be respectful when communicating with other contributors.

Contributions that contain misleading information, unnecessary promotional content, or unrelated modifications may be declined.

## Running the Documentation Locally

You can preview your changes locally before submitting a pull request.

### Requirements

- [Node.js](https://nodejs.org/)
- [Mintlify CLI](https://www.npmjs.com/package/mint)

Install the Mintlify CLI:

```bash
npm install -g mint
```

Clone your fork:

```bash
git clone https://github.com/riotscc/documentation.git
```

Navigate to the project directory:

```bash
cd documentation
```

Start the local development server:

```bash
mint dev
```

Open the local URL displayed in your terminal to preview the documentation.

## Reporting Issues

Found incorrect information, a broken link, or something that could be explained better?

Open a [GitHub Issue](../../issues) and include:
