## Start with the basics

<Steps>
  <Step title="Refresh the page">Try a normal reload, then a hard refresh if needed.</Step>
  <Step title="Check connectivity">Confirm your connection is working and try a different network if appropriate.</Step>
  <Step title="Try a private window">Check whether a browser extension or cached session is interfering.</Step>
  <Step title="Record the details">Note the page URL, exact error message, and steps that reproduce the issue.</Step>
</Steps>
